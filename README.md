# TWRA Aroma Diffuser для Home Assistant

Локальное управление аромадиффузором **Tersway TW-RA01 Smart Tower** (Bluetooth-имя `TWRA01B-…`, приложение «Aroma Diffuser») по Bluetooth, без облака. Интеграция сразу рассчитана на передачу в Apple HomeKit через HomeKit Bridge.

## Что умеет

| В Home Assistant | Что делает | В приложении «Дом» |
|---|---|---|
| `fan.<имя>` | Питание диффузора и интенсивность аромата | Плитка «Вентилятор»: вкл/выкл + ползунок |
| `light.<имя>_lamp` (Подсветка) | Подсветка: белый, голубой, оранжевый, выкл. | Лампа с выбором цвета |
| `switch.<имя>_mode_N` | Включить/выключить рабочий режим N | не передаётся |
| `time.…_start` / `time.…_end` | Время начала/конца режима | не передаётся |
| `number.…_spray_time` / `number.…_pause` | Распыление и пауза режима, секунды | не передаётся |
| Служба `twra_diffuser.set_working_mode` | Всё сразу, включая дни недели | — |

Настройки режимов помечены как служебные (`entity_category: config`), поэтому HomeKit Bridge по умолчанию их не передаёт. В «Доме» остаются только две понятные плитки.

**Интенсивность.** Диффузор работает циклами «распыление N секунд, пауза M секунд» внутри рабочих режимов. Ползунок меняет паузу во всех включённых режимах, а время распыления не трогает:

| Ползунок | 1–16 % | 17–33 % | 34–50 % | 51–66 % | 67–83 % | 84–100 % |
|---|---|---|---|---|---|---|
| Пауза | 900 с | 600 с | 450 с | 300 с | 180 с | 90 с |

**Подсветка.** У лампы всего три цвета. Цвет из палитры HomeKit подстраивается под ближайший: белые и бледные оттенки → белый, синие и зелёные → голубой, красные и жёлтые → оранжевый. Яркость не регулируется.

**Расписание.** Диффузор распыляет только в часы и дни включённых рабочих режимов. При каждом подключении и раз в 6 часов интеграция синхронизирует часы диффузора по времени Home Assistant.

## Что нужно

- Home Assistant 2025.6 или новее.
- Bluetooth, который достаёт до диффузора: встроенный или USB-адаптер на сервере HA либо **ESPHome Bluetooth Proxy** на ESP32 рядом с диффузором. Прокси должен поддерживать активные подключения; в готовой прошивке с esphome.io это включено.
- Для управления не из дома: **домашний центр Apple** (Apple TV, HomePod или HomePod mini). Через него HomeKit работает удалённо.

## Установка

### Вариант A: через HACS (удобно обновлять)
HACS скачивает интеграции только из публичных репозиториев.
1. В HA: **HACS → ⋮ → Custom repositories** → `https://github.com/Arenchik/ipad-playground`, тип **Integration** → **Add**.
2. Найдите «TWRA Aroma Diffuser» в HACS → **Download**.
3. Перезапустите Home Assistant.

### Вариант B: вручную
1. Скопируйте папку `custom_components/twra_diffuser` в `/config/custom_components/` на сервере HA. Подойдут Samba share, Studio Code Server или SSH.
2. Перезапустите Home Assistant.

## Добавление диффузора

1. **Закройте приложение Aroma Diffuser на телефоне.** Диффузор принимает только одно подключение.
2. HA сам найдёт диффузор: «Настройки → Устройства и службы», карточка «Обнаружено: TWRA01B-…» → **Настроить**. Если карточки нет: **Добавить интеграцию → TWRA Aroma Diffuser**.
3. Введите название, например «Аромадиффузор». Под этим именем устройство появится в HomeKit.
4. Проверьте, что в карточке устройства работают питание и подсветка.

**Параметры интеграции** («Настроить» в карточке интеграции):
- *Держать Bluetooth-подключение* — включено по умолчанию. Команды выполняются мгновенно, состояние всегда актуальное. Минус: приложение на телефоне в это время подключиться не сможет.
- Если выключить, HA подключается только на время команды и раз в 5 минут для обновления состояния. Между этим можно пользоваться приложением на телефоне. Команды из HomeKit тогда выполняются за 2–4 секунды.

## Подключение к Apple HomeKit

1. **Настройки → Устройства и службы → Добавить интеграцию → HomeKit Bridge**.
2. В списке доменов оставьте **Fan** и **Light** и нажмите **Отправить**. Если у вас уже есть мост HomeKit Bridge, откройте его «Настроить» и добавьте `fan.<имя>` и `light.<имя>_lamp` в список включённых сущностей.
3. Если хотите передать только диффузор: «Настроить» → режим **Включить** (include) → выберите две сущности: диффузор и его подсветку.
4. В уведомлениях HA появится QR-код. На iPhone: **«Дом» → «+» → «Добавить аксессуар»** → отсканируйте код.
5. В «Доме» появятся «Аромадиффузор» (вентилятор с ползунком) и «Подсветка». Их можно разложить по комнатам, добавить в сценарии и автоматизации и управлять голосом: «Siri, включи аромадиффузор», «Siri, поставь аромадиффузор на 50 %».

Что учесть:
- iPhone и сервер HA при сопряжении должны быть в одной сети. Если HA работает в Docker, контейнеру нужен `network_mode: host`.
- Имена в «Доме» берутся в момент сопряжения. Переименуйте устройство в HA заранее.

## Служба `set_working_mode`

Меняет рабочий режим, сохранённый в диффузоре; меняются только указанные поля. Новые режимы создаются в приложении Aroma Diffuser. После этого HA сам перезагрузит интеграцию и добавит сущности нового режима.

```yaml
action: twra_diffuser.set_working_mode
data:
  device_id: <выберите устройство в редакторе>
  mode: 1
  enabled: true
  days: [mon, tue, wed, thu, fri]
  start: "08:00"
  end: "22:00"
  run_seconds: 16
  pause_seconds: 300
```

## Если что-то не работает

- **Устройство не находится / «недоступно».** Закройте приложение на телефоне. Проверьте, что диффузор виден в «Настройки → Bluetooth → Advertisement monitor» с сигналом лучше примерно −85 dBm. Если нет — поставьте Bluetooth-прокси ближе к диффузору.
- **Подробный журнал.** Добавьте в `configuration.yaml`:
  ```yaml
  logger:
    logs:
      custom_components.twra_diffuser: debug
  ```
- **Диагностика.** Карточка устройства → ⋮ → «Скачать диагностику»: состояние, режимы и сырые данные с устройства. Пароль, если он задан, в файл не попадает.

## Как это устроено

Диффузор использует протокол YooAI «Scent Tech» на характеристике `FFE1`: кадры `55 AA LEN CMD DATA CHK 5A`. Код протокола и BLE-клиента лежит в `twra.py` и не зависит от Home Assistant. Все команды проверены на настоящем TWRA01B:

| Команда | Кадр | Ответ |
|---|---|---|
| Питание вкл/выкл | `07 12 01 00` / `07 12 00 00` | `87 00`, затем состояние `21` |
| Следующий цвет подсветки | `07 15 xx 00` (значение игнорируется) | `87 00`, затем состояние `21` |
| Прочитать режимы | `08` | `88`: количество + записи по 16 байт |
| Записать режим | `14` + запись 16 байт | `94 00` |
| Часы | `06` + u32 (местное время как UTC) | — |

Команду `07 01` («Restore» в приложении, вероятно, сброс к заводским настройкам) интеграция не использует.
